### 3. Key Files Created

#### init.sh
- Checks prerequisites (Node.js 20+, npm/pnpm, Git)
- Creates .env files from examples
- Installs dependencies for all packages
- Generates Prisma client
- Runs database migrations (if database available)
- Starts development servers
- Usage: `./init.sh [api|mobile|all|setup-only]`

#### Prisma Schema
Complete database schema with all tables from spec:
- schools, users, guardians, students
- guardian_students (many-to-many)
- cafeterias, menu_items, recharge_packages
- wallets, student_tickets, wallet_logs
- transactions, orders, payments
- push_tokens, notifications, refresh_tokens

All enums defined:
- UserRole, GuardianRelationship
- RechargePackageType, WalletLogType
- TransactionType, ValidationMethod, TransactionSource
- OrderStatus, PaymentGateway, PaymentStatus

#### Shared Utilities
- **RUT Validation**: Full Chilean RUT validation with verification digit calculation
- **CLP Formatting**: Chilean Peso formatting without decimals

#### Theme Constants
- Colors: Primary coral (#FF4D6D), success, warning, error, etc.
- Typography: h1-h4, body, labels, captions
- Spacing, border radius, shadows
